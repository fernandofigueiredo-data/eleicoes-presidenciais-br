  1. Qual foi o resultado de cada eleição e turno, no país, por UF e por município?

Etapa 2 de 8

Limpeza dos dados no Power Query

A limpeza parte do arquivo data/eleicoes_presidente.csv (22 colunas, uma linha por candidato, zona e turno) e gera 5 tabelas organizadas em modelo estrela. É a mesma limpeza do notebook notebooks/limpeza_dados.ipynb: os nomes das tabelas, das colunas e o número de linhas são iguais.

      │                                │
      └──────► fComparecimento ◄───────┘
TabelaTipoUma linha =Linhas
Eleicoesapoio (não carrega)candidato × zona × turno, já limpo340.702
dTurnodimensãoeleição e turno8

dMunicipiodimensãomunicípio ou cidade do exterior5.766
fVotosfatovotos de um candidato em um município, em um turno309.308
fComparecimentofatoeleitorado e comparecimento de um município, em um turno45.834

Por que esse formato

  • Os totais de zona (aptos, comparecimento, brancos, nulos) se repetem em cada candidato no arquivo original. Separar votos e comparecimento em tabelas diferentes elimina o risco de somar o mesmo total várias vezes.
  • Cada informação fica em um lugar só (o nome do município está só em dMunicipio), e os filtros do dashboard funcionam em todas as tabelas ao mesmo tempo.
  • Os dados ficam no nível de município, que é o usado em todas as perguntas.

Cada consulta abaixo tem o passo a passo pelos menus e o código M equivalente. Você pode seguir os cliques ou colar o código em Página Inicial > Editor Avançado. Os nomes dos passos no código são os mesmos citados no notebook.

2.1 Parâmetro com o caminho do arquivo

Página Inicial > Gerenciar Parâmetros > Novo Parâmetro

  • Nome: CaminhoArquivo
  • Tipo: Texto

2.2 Consulta de apoio Eleicoes

É a base limpa da qual saem todas as outras tabelas.

Pelos menus

  1. Nova Fonte > Texto/CSV > eleicoes_presidente.csv > Delimitador Ponto e vírgula > Transformar dados. Renomeie a consulta para Eleicoes.
  2. Fonte: no passo Fonte, troque o caminho pelo parâmetro CaminhoArquivo.
  3. Tipos: selecione as colunas e defina o tipo (Transformar > Tipo de Dados):
    • Número inteiro: ano, nr_turno, cd_municipio_tse, cd_municipio_ibge, nr_zona, nr_candidato, qt_votos_nominais, todas as zona_* e populacao_2022
    • Número decimal: alfabetizacao_2022, pib_mil_reais
    • Texto: as demais
  4. Textos: selecione municipio, nm_urna, sg_partido, sg_uf, situacao_turno > Transformar > Formato > Aparar (tira espaços do começo e do fim).
  5. Regiao: selecione sg_regiao > Substituir Valores: valor vazio por EX. Os vazios são todos do exterior (sg_uf = ZZ).
  6. NomeRegiao: Adicionar Coluna > Coluna Condicional sg_regiao_nome: N → Norte, NE → Nordeste, SE → Sudeste, S → Sul, CO → Centro-Oeste, senão → Exterior.
  7. NomeUF: coluna sg_uf_nome com o nome do estado por extenso (use o código abaixo; pelos menus seria uma coluna condicional com 28 regras).
  8. Exterior: Coluna Personalizada exterior = [sg_uf] = "ZZ", tipo Verdadeiro/Falso.
  9. MunicipioUF: Coluna Personalizada municipio_uf = [municipio] & " (" & [sg_uf] & ")".
  10. PartidoAtual: Coluna Condicional partido_atual: se sg_partido = PSDC então DC, senão o próprio sg_partido (o PSDC mudou de nome para DC em 2017).
  11. ChaveTurno: Coluna Personalizada chave_turno = Text.From([ano]) & "-" & Text.From([nr_turno])
  12. ChaveCandidato: Coluna Personalizada chave_candidato = Text.From([ano]) & "-" & Text.From([nr_candidato])
  13. Clique direito na consulta > desmarque Habilitar carga. Ela serve só de base.

let
    Fonte = Csv.Document(
        File.Contents(CaminhoArquivo),
        [Delimiter = ";", Encoding = 65001, QuoteStyle = QuoteStyle.Csv]
    ),
    Cabecalhos = Table.PromoteHeaders(Fonte, [PromoteAllScalars = true]),
    Tipos = Table.TransformColumnTypes(
        Cabecalhos,
        {
            {"ano", Int64.Type}, {"nr_turno", Int64.Type},
            {"sg_regiao", type text}, {"sg_uf", type text},
            {"cd_municipio_tse", Int64.Type}, {"cd_municipio_ibge", Int64.Type},
            {"municipio", type text}, {"nr_zona", Int64.Type},
            {"nr_candidato", Int64.Type}, {"nm_urna", type text},
            {"sg_partido", type text}, {"situacao_turno", type text},
            {"qt_votos_nominais", Int64.Type},
            {"zona_aptos", Int64.Type}, {"zona_comparecimento", Int64.Type},
            {"zona_abstencoes", Int64.Type}, {"zona_votos_validos", Int64.Type},
            {"zona_votos_brancos", Int64.Type}, {"zona_votos_nulos", Int64.Type},
            {"populacao_2022", Int64.Type}, {"alfabetizacao_2022", type number},
            {"pib_mil_reais", type number}
        },
        "en-US"
    ),
    Textos = Table.TransformColumns(
        Tipos,
        {
            {"municipio", Text.Trim, type text}, {"nm_urna", Text.Trim, type text},
            {"sg_partido", Text.Trim, type text}, {"sg_uf", Text.Trim, type text},
            {"situacao_turno", Text.Trim, type text}
        }
    ),
    Regiao = Table.TransformColumns(
        Textos,
        {{"sg_regiao", each if _ = null or _ = "" then "EX" else _, type text}}
    ),
    Regioes = [N = "Norte", NE = "Nordeste", SE = "Sudeste", S = "Sul", CO = "Centro-Oeste", EX = "Exterior"],
    NomeRegiao = Table.AddColumn(
        Regiao, "sg_regiao_nome", each Record.FieldOrDefault(Regioes, [sg_regiao], "Exterior"), type text
    ),
    UFs = [
        AC = "Acre", AL = "Alagoas", AP = "Amapá", AM = "Amazonas", BA = "Bahia", CE = "Ceará",
        DF = "Distrito Federal", ES = "Espírito Santo", GO = "Goiás", MA = "Maranhão",
        MT = "Mato Grosso", MS = "Mato Grosso do Sul", MG = "Minas Gerais", PA = "Pará",
        PB = "Paraíba", PR = "Paraná", PE = "Pernambuco", PI = "Piauí", RJ = "Rio de Janeiro",
        RN = "Rio Grande do Norte", RS = "Rio Grande do Sul", RO = "Rondônia", RR = "Roraima",
        SC = "Santa Catarina", SP = "São Paulo", SE = "Sergipe", TO = "Tocantins", ZZ = "Exterior"
    ],
    NomeUF = Table.AddColumn(
        NomeRegiao, "sg_uf_nome", each Record.FieldOrDefault(UFs, [sg_uf], "Exterior"), type text
    ),
    Exterior = Table.AddColumn(NomeUF, "exterior", each [sg_uf] = "ZZ", type logical),
    MunicipioUF = Table.AddColumn(
        Exterior, "municipio_uf", each [municipio] & " (" & [sg_uf] & ")", type text
    ),
    PartidoAtual = Table.AddColumn(
        MunicipioUF, "partido_atual", each if [sg_partido] = "PSDC" then "DC" else [sg_partido], type text
    ),
    ChaveTurno = Table.AddColumn(
        PartidoAtual, "chave_turno", each Text.From([ano]) & "-" & Text.From([nr_turno]), type text
    ),
    ChaveCandidato = Table.AddColumn(
        ChaveTurno, "chave_candidato", each Text.From([ano]) & "-" & Text.From([nr_candidato]), type text
    )
in
    ChaveCandidato
2.3 Dimensão dTurno

Clique direito em Eleicoes > Referência. Renomeie para dTurno.

  1. Escolher Colunas: chave_turno, ano, nr_turno
  2. Remover Linhas > Remover Duplicatas
  3. Coluna Personalizada rotulo_turno = Text.From([ano]) & " · " & Text.From([nr_turno]) & "º turno"
  4. Coluna Personalizada ordem_turno = [ano] * 10 + [nr_turno] (Número inteiro)
  5. Classificar ordem_turno em ordem crescente
Código M equivalente · 11 linhas
let
    Fonte = Eleicoes,
    Colunas = Table.SelectColumns(Fonte, {"chave_turno", "ano", "nr_turno"}),
    Unicos = Table.Distinct(Colunas),
    Rotulo = Table.AddColumn(
        Unicos, "rotulo_turno", each Text.From([ano]) & " · " & Text.From([nr_turno]) & "º turno", type text
    ),
    Ordem = Table.AddColumn(Rotulo, "ordem_turno", each [ano] * 10 + [nr_turno], Int64.Type),
    Ordenado = Table.Sort(Ordem, {{"ordem_turno", Order.Ascending}})
in
    Ordenado

2.5 Dimensão dMunicipio

Referência de Eleicoes > renomeie para dMunicipio.

O PIB muda a cada ano. Para descrever o perfil do município, uso o mais recente (2023, ou 2022 quando o de 2023 não foi publicado), que está nas linhas de 2022 e 2026.

Atenção ao tipo do PIB. Crie pib_ref e a agregação pib_mil_reais com tipo Número decimal. Sem tipo, a Coluna Condicional sai como "qualquer" e o pib_mil_reais chega ao modelo como texto, e aí SUM não funciona nele. O código abaixo já define os tipos.
  1. Coluna Condicional pib_ref: se ano ≥ 2022 então pib_mil_reais, senão null
  2. Agrupar Por (Avançado) pelas colunas cd_municipio_tse, cd_municipio_ibge, municipio, municipio_uf, sg_uf, sg_uf_nome, sg_regiao, sg_regiao_nome, exterior, populacao_2022, alfabetizacao_2022, com a agregação pib_mil_reais = Máximo de pib_ref
  3. Coluna Personalizada pib_per_capita = [pib_mil_reais] * 1000 / [populacao_2022] (o PIB está em mil reais), tipo Número decimal
  4. Coluna Condicional faixa_populacao: vazio → Sem dado; até 5.000 → Até 5 mil; até 20.000 → 5 a 20 mil; até 100.000 → 20 a 100 mil; até 500.000 → 100 a 500 mil; senão → Mais de 500 mil
  5. Coluna Condicional ordem_faixa_populacao com os números 0 a 5 na mesma ordem
  6. Coluna Personalizada local_mapa: para o Brasil, [municipio] & ", " & [sg_uf_nome] & ", Brasil"; para o exterior, só [municipio]. É o endereço que o mapa usa (com o estado, para não confundir municípios com o mesmo nome).
Código M equivalente · 45 linhas
let
    Fonte = Eleicoes,
    PibRef = Table.AddColumn(
        Fonte, "pib_ref", each if [ano] >= 2022 then [pib_mil_reais] else null, type nullable number
    ),
    Agrupado = Table.Group(
        PibRef,
        {"cd_municipio_tse", "cd_municipio_ibge", "municipio", "municipio_uf", "sg_uf", "sg_uf_nome",
         "sg_regiao", "sg_regiao_nome", "exterior", "populacao_2022", "alfabetizacao_2022"},
        {{"pib_mil_reais", each List.Max([pib_ref]), type nullable number}}
    ),
    PibPerCapita = Table.AddColumn(
        Agrupado, "pib_per_capita",
        each if [pib_mil_reais] = null or [populacao_2022] = null then null
             else [pib_mil_reais] * 1000 / [populacao_2022],
        type nullable number
    ),
    Faixa = Table.AddColumn(
        PibPerCapita, "faixa_populacao",
        each if [populacao_2022] = null then "Sem dado"
             else if [populacao_2022] <= 5000 then "Até 5 mil"
             else if [populacao_2022] <= 20000 then "5 a 20 mil"
             else if [populacao_2022] <= 100000 then "20 a 100 mil"
             else if [populacao_2022] <= 500000 then "100 a 500 mil"
             else "Mais de 500 mil",
        type text
    ),
    OrdemFaixa = Table.AddColumn(
        Faixa, "ordem_faixa_populacao",
        each if [populacao_2022] = null then 0
             else if [populacao_2022] <= 5000 then 1
             else if [populacao_2022] <= 20000 then 2
             else if [populacao_2022] <= 100000 then 3
             else if [populacao_2022] <= 500000 then 4
             else 5,
        Int64.Type
    ),
    LocalMapa = Table.AddColumn(
        OrdemFaixa, "local_mapa",
        each if [exterior] then [municipio] else [municipio] & ", " & [sg_uf_nome] & ", Brasil",
        type text
    ),
    Ordenado = Table.Sort(LocalMapa, {{"cd_municipio_tse", Order.Ascending}})
in
    Ordenado

Etapa 3 de 8

Modelo de dados

3.1 Relacionamentos (Exibição de modelo)

Todos um para muitos, filtro em direção única:

dTurno[chave_turno]            1 ──► * fVotos[chave_turno]
dTurno[chave_turno]            1 ──► * fComparecimento[chave_turno]
dMunicipio[cd_municipio_tse]   1 ──► * fVotos[cd_municipio_tse]
dMunicipio[cd_municipio_tse]   1 ──► * fComparecimento[cd_municipio_tse]
dCandidato[chave_candidato]    1 ──► * fVotos[chave_candidato]

Apague relacionamentos automáticos diferentes destes (por exemplo, pela coluna ano).

3.2 Ajustes de modelo
  • dTurno[rotulo_turno] > Ferramentas de coluna > Classificar por coluna > ordem_turno
  • dMunicipio[faixa_populacao] > Classificar por coluna > ordem_faixa_populacao
  • dMunicipio[sg_uf_nome] > Categoria de dados: Estado ou Província
  • dMunicipio[local_mapa] > Categoria de dados: Local
  • Nas tabelas de fatos, oculte as chaves e as colunas ano e nr_turno (clique direito > Ocultar na exibição de relatório): os filtros usam sempre as dimensões.
  • Oculte também ordem_turno e ordem_faixa_populacao.
  • Quantidades e população com separador de milhar; pib_per_capita como Moeda (R$).

Etapa 4 de 8

Medidas DAX

Faça esta etapa depois da limpeza: as medidas usam os nomes de tabelas e colunas da etapa 2.

  1. Página Inicial > Inserir dados > nomeie a tabela _Medidas > Carregar.
  2. Modelagem > Nova tabela > cole PartidoCores de medidas_dax.dax.
  3. Em dMunicipio, Nova coluna: Quartil PIB per capita e Quartil Alfabetização. Os quartis ficam no DAX porque precisam comparar todos os municípios ao mesmo tempo.
  4. Em _Medidas, crie cada medida (Nova medida) e organize em pastas (Propriedades > Pasta de exibição), seguindo os comentários Pasta: do arquivo.
  5. Formatos:
    • Medidas com % > Porcentagem, 2 casas
    • Variação p.p., Variação Abstenção p.p. e Variação entre Turnos p.p. > formato personalizado +0.0" p.p.";-0.0" p.p."
    • Contagens e votos > Número inteiro com separador de milhar
    • PIB per capita > Moeda (R$), sem casas decimais
  6. Exclua a coluna vazia de _Medidas: ela vira uma tabela de medidas e sobe para o topo da lista.

Ficam na tabela PartidoCores e são aplicadas pelas medidas Cor do Partido e Cor do Partido Vencedor. Os principais partidos têm cor própria; os menores ficam em tons de cinza, o que destaca quem disputou de fato sem esconder ninguém.

As cores partem da identidade visual de cada partido e foram ajustadas para que partidos da mesma eleição não fiquem parecidos (ex.: o PDT em roxo para não confundir com o vermelho do PT em 2018 e 2022). Ajuste os códigos na tabela se quiser.

Como aplicar em um gráfico de barras: selecione o visual > Formatar > Barras > Cores > fx > Estilo de formato Valor do campo > campo Cor do Partido.

Regras de neutralidade
  • Mesmo tamanho, fonte e destaque para todos os candidatos; a ordem é sempre por votos.
  • Sem adjetivos nos títulos: "Votos válidos por candidato", e não "Vitória esmagadora".
  • Cor vem do partido, nunca de "bom" ou "ruim".
  • Mostrar sempre o número junto da cor (rótulos de dados ligados), para não depender só da cor.

Etapa 6 de 8

Cabeçalho (igual em todas as páginas)

Monte na primeira página e copie para as outras.

  1. Inserir > Formas > Retângulo: 1920 × 96 px, posição (0, 0), cor #002776, sem borda.
  2. Dois retângulos finos logo abaixo, como uma faixa da bandeira: 6 px de altura, um verde #009C3B (0 a 960 px) e um amarelo #FFDF00 (960 a 1920 px).
  3. Cartão com a medida Título Eleição: fundo transparente, texto branco, 18–20, alinhado à esquerda, sem rótulo de categoria.
  4. Segmentação com dTurno[rotulo_turno]: estilo Lista suspensa, seleção única, no canto direito do cabeçalho. Em Exibir > Sincronizar segmentações, sincronize com todas as páginas.
  5. Inserir > Botões > Navegador > Navegador de página, para trocar de página.

Limitações para a caixa de texto

  • O exterior não tem dados do IBGE; em 2014 e 2018 faltam 684 e 470 eleitores aptos de zonas do exterior onde ninguém votou.
  • Boa Esperança do Norte (MT) foi criado depois do Censo 2022 e não tem indicadores.
  • O 2º turno de 2026 (25/10/2026) vem dos arquivos publicados pelo TSE em 28/10/2026.
  • O perfil econômico usa o PIB mais recente (2023) e a população de 2022.
